# 📊 Retail Sales Analysis using SQL

Retail Sales Analysis is a SQL-based data analytics project focused on extracting meaningful business insights from retail sales data. The project demonstrates the use of SQL for data cleaning, querying, and performance analysis to understand sales trends, customer purchasing behavior, and product performance. Advanced SQL concepts such as Joins, Common Table Expressions (CTEs), Window Functions, Aggregate Functions, and Subqueries were used to generate key business reports and support data-driven decision-making.

## 🛠️ Tech Stack

- MySQL
- SQL

## ✨ Key Features

- Data Cleaning & Validation
- Sales Performance Analysis
- Customer Purchase Analysis
- Product Performance Insights
- Revenue & KPI Reporting
- Joins, CTEs & Window Functions
- Aggregate Functions & Subqueries
- Business-Oriented SQL Reporting
